# Задание 3. Оценка Data Encryption at Rest and In Transit

## Классификация данных и меры защиты

| Данные                                                                   | В чём необходимость защиты                                                                              | Инструменты защиты                                                        |
|--------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------|
| Персональные данные пациента (ФИО, дата рождения, телефон, email, адрес) | Являются персональными данными согласно 152-ФЗ. Утечка может привести к штрафам и репутационным потерям | Шифрование БД (AES-256), TLS 1.3, RBAC/ABAC, аудит доступа                |
| Медицинские данные (диагнозы, анализы, назначения, заключения)           | Относятся к специальным категориям персональных данных и медицинской тайне                              | Шифрование БД (AES-256), TLS 1.3, токенизация, аудит, Data Classification |
| Финансовые данные (платежи, чеки, счета)                                 | Могут использоваться для мошенничества и финансовых преступлений                                        | TLS 1.3, шифрование БД, контроль доступа, журналирование                  |
| Договоры и согласия                                                      | Содержат персональные данные и юридически значимую информацию                                           | Шифрование файлового хранилища, TLS 1.3, контроль доступа                 |
| Учётные записи пользователей                                             | Компрометация приводит к несанкционированному доступу                                                   | MFA, Argon2/Bcrypt, TLS 1.3                                               |
| API-ключи, сертификаты, пароли БД                                        | Предоставляют доступ к критическим системам                                                             | Hashicorp Vault, ротация секретов                                         |
| Аналитические данные в Data Lake                                         | Используются для BI/ML/AI, могут содержать косвенные идентификаторы                                     | Псевдонимизация, маскирование, разграничение доступа                      |
| Журналы аудита                                                           | Используются для расследования инцидентов                                                               | Неизменяемое хранение, контроль целостности                               |
