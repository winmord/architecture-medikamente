# Список проблемных зон

| №  | Проблемная зона                                 | Описание                                                                                                                          | 
|----|-------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------|
| 1  | **Отсутствие аудита доступа**                   | Нет логирования того, кто, когда и к каким данным обращался. Невозможно отследить несанкционированные действия.                   | 
| 2  | **Хранение PII в открытом виде на общем диске** | Все файлы (Excel, JPG, PDF) с персональными и медицинскими данными лежат на общем диске без шифрования.                           | 
| 3  | **Нет RBAC/ABAC**                               | Любой сотрудник потенциально имеет доступ к любым данным пациента — нет разграничения прав доступа.                               | 
| 4  | **Нет разграничения по доменам данных**         | Медицинские, финансовые, персональные и операционные данные смешаны в одних хранилищах (общий диск, Excel).                       | 
| 5  | **Отсутствие DLP/мониторинга**                  | Нет систем контроля утечек данных и мониторинга нештатных действий пользователей.                                                 | 
| 6  | **Файловый режим 1С**                           | 1С:Бухгалтерия и 1С:Торговля и склад работают в файловом режиме. Файлы баз данных лежат на общем доступе без защиты на уровне БД. | 
| 7  | **Excel без паролей и шифрования**              | Все Excel-файлы с конфиденциальными данными хранятся и передаются в открытом тексте.                                              | 
| 8  | **Нет политики Data Minimization**              | Собирается избыточная информация (место работы, учёба, адрес прописки) без явной медицинской необходимости.                       | 
| 9  | **Нет жизненного цикла данных**                 | Отсутствуют регламенты сроков хранения и порядка уничтожения данных. Нет механизмов удаления по запросу пациента.                 | 
| 10 | **Двойной учёт (Excel + 1С)**                   | Кассиры ведут двойной учёт платежей — в Excel и 1С. Избыточное дублирование увеличивает риски ошибок и утечек.                    | 
| 11 | **Нет шифрования в каналах передачи**           | Взаимодействие между 1С и ККМ по TCP/IP через OLE — данные передаются в открытом виде.                                            | 
| 12 | **Отсутствие Privacy By Design**                | Все системы проектировались без учёта защиты данных с самого начала, безопасность добавлена "сверху" точечно.                     | 
| 13 | **Нет тегирования данных**                      | Отсутствует классификация и маркировка данных по уровню чувствительности. Непонятно, какие данные являются чувствительными.       | 
| 14 | **Лабораторные данные в открытом доступе**      | Реестры анализов (Excel) лежат на общем диске без разграничения доступа. Результаты анализов — особо чувствительные данные.       | 
| 15 | **Нет механизма обезличивания**                 | Отсутствуют процессы обезличивания данных для аналитики и разработки.                                                             | 
| 16 | **Нет обработки запросов пациентов**            | Отсутствует механизм приёма и исполнения запросов пациентов на удаление/изменение данных.                                         | 
| 17 | **Сканы без OCR и структурирования**            | Медицинские карты, договоры, заключения хранятся как изображения без извлечения данных в структурированный вид.                   | 
| 18 | **Ручная обработка данных**                     | Все операции с данными выполняются вручную — от записи до сверки платежей, что повышает риск ошибок.                              |
